# Handover: read this first

Repository: https://github.com/3bHussein/Project-Factory-AI

1. Inspect `PROJECT-STATE.md` and `DEVELOPMENT-LOG.md`.
2. Check open pull requests, newest commits, GitHub Actions run statuses and `automation-runs/`.
3. Read `DECISIONS.md`, `COMPATIBILITY.md`, `ARCHITECTURE.md`, `TEST-REPORT.md`.
4. Work only on a new branch based on latest main; keep manual review before merging.
5. Run `python -m unittest discover -s tests -v` and test relevant workflows.
6. Update state, changelog, decisions and log with actual outcomes in the same PR.
7. Never modify other repositories or use paid services without user approval.

Reminder: Git history captures committed work only; external tools and chats require explicit logging.
