How the factory works

💡 Choose ideas

Daily automation picks a backlog idea and creates a review-only proposal.

🛠 Build a starter

Manual GitHub Actions can generate an offline Python text-statistics starter with 10 docs and tests.

✅ Validate

Quality gates test code and documentation. Humans review pull requests before merging.

Current limitation: Daily runs generate specifications, not finished AI-coded apps. The starter generator has one fixed template, not different tools for every idea.

Quick start

Install Python 3.10+ and Git. Then run:

git clone https://github.com/3bHussein/Project-Factory-AI.git
cd Project-Factory-AI
python -m unittest discover -s tests -v
python scripts/validate_projects.py

On Linux, use python3 if needed. This dashboard is a static HTML page; browser buttons cannot run Python on your machine.
