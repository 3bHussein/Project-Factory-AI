# Handover

Start with README.md, ARCHITECTURE.md, SECURITY.md and TEST-REPORT.md. Run `python -m unittest discover -s projects/port-inspector/tests -v` from repository root, then run the CLI on a real Windows and Linux machine. Review open issues and pull requests before editing. Keep behavior read-only and avoid adding dependencies without justification. Known limitations: no Linux PID attribution and no Windows UDP reporting. Document all fixes in DEVELOPMENT-LOG.md and CHANGELOG.md.
