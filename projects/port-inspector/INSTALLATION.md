# Installation

Install Python 3.10+ on Windows or Linux. Windows requires the built-in `netstat` utility; Linux requires `ss` (normally supplied by `iproute2`). Clone this repository and change into `projects/port-inspector`. Run `python port_inspector.py --help` on Windows, or `python3 port_inspector.py --help` on Linux. No pip dependencies or administrator permissions are required for basic output.
