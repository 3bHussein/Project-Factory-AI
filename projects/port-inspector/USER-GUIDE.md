# User Guide

Run `python port_inspector.py` to display local listening TCP ports as CSV on Windows, or TCP/UDP ports on Linux. Use `--json` to produce machine-readable output. Use `--port 8080` to filter one port. On Linux use `python3` if `python` is not installed. Do not interpret an open local port as proof of external reachability. Review results before sharing because local service details may be sensitive.
